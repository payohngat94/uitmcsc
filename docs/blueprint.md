# **App Name**: SimuLearn Hub

## Core Features:

- Learning Materials Module: Centralized repository for videos, documents, and slides, categorized by clinical skill.
- Booking System: Session booking with calendar view and admin approval/auto-confirmation.
- Inventory Management: Equipment inventory list with status tracking and request form.
- Announcements & Events: Admin-posted course and training announcements with notification/email alerts.
- User Authentication: Login with student email / institutional ID and admin role for staff.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) for a luxurious and academic feel.
- Background color: Light gray (#F5F5F5) for a clean and modern look.
- Accent color: Teal (#009688) to complement purple and provide visual interest.
- Headline font: 'Playfair' serif for elegant headlines. Body font: 'PT Sans' sans-serif for readability. 
- Use simple, clean icons that align with the minimalistic style.
- Employ a grid-based layout for organized and responsive content display.
- Subtle animations and transitions to enhance user experience and provide feedback.
